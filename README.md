# Oluwatimilehin Sapara — Portfolio Website

A responsive personal portfolio showcasing my background, technical skills, software projects, résumé, and highlights from my academic and professional experiences.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Git and GitHub
- GitHub Pages

## GitHub Pages Deployment

View the deployed website at [https://timii0.github.io/create_website/](https://timii0.github.io/create_website/).

## Viewing the Project

To view the deployed version, open the GitHub Pages link above in any modern web browser. Use the navigation bar to visit the Projects page, browse the Gallery, or open the résumé.

To view the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/timii0/create_website.git
   ```

2. Open the project directory:

   ```bash
   cd create_website
   ```

3. Open `index.html` in a web browser. No installation or build process is required.
